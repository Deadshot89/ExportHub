# Commands (Windows, Git Bash/PowerShell)
- `npm test` (laeuft mit pretest `scripts/rc1462-pretest.mjs` und posttest `scripts/rc1520-posttest-release-isolation.mjs`).
- `npm run verify:release` = test:security + test:accessibility + test.
- `npm run verify:i18n`, `npm run i18n:audit:strict`, `npm run test:security`, `npm run test:smoke`.
- GitHub: `gh pr list`; GitHub-MCP-Plugin kann ausfallen, `gh` ist authentifiziert.
- Python ist nicht installiert (Store-Alias), Skripte mit Node schreiben.
